# Funcionalidade: Não afirmar o que a fonte não confirma

## Regra: Fato sem fonte vira pergunta

### Exemplo: Detalhe que a fonte não traz

- Dado que o texto cita uma função que a base do projeto não confirma
- Quando a resposta é montada
- Então a função não entra como afirmação
- E ela aparece em "Sem conferir", escrita como pergunta

### Exemplo: Promessa não combinada

- Dado que a pessoa pede para prometer desconto
- Quando a condição não foi combinada
- Então a promessa é recusada e a pessoa responde se ela existe
