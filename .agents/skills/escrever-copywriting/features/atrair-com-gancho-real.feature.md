# Funcionalidade: Atrair quem não conhece a marca com um gancho real

## Regra: Cada opção parte de um gancho com fonte

### Exemplo: Pedido de comentário público

- Dado que a base do projeto tem a ficha técnica de uma peça
- Quando a pessoa pede um comentário para o post de uma loja coletiva
- Então a resposta traz de 2 a 3 opções de gancho diferente
- E cada opção diz o gancho, a fonte e por que atrai quem não conhece a marca

### Exemplo: Opção que parece copy

- Dado que uma opção abre com elogio, adjetivo e "venha"
- Quando a checagem anti-clichê roda
- Então a opção é reprovada e reescrita com um gancho concreto
