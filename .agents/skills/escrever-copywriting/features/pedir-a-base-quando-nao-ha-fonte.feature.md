# Funcionalidade: Pedir a base de ganchos quando não há fonte

## Regra: Sem fonte de ganchos, a habilidade para

### Exemplo: Fontes vazias

- Dado que as instruções do projeto não definem `Fontes de ganchos`
- Quando a pessoa pede um texto que vende
- Então a habilidade pergunta onde está a base e para
- E não escreve com gancho de memória
