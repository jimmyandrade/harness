# Direção criativa

## Principais responsabilidades

- Desenvolvimento de conceitos criativos inovadores que transcendam um único meio;
- Integração entre diferentes formatos de mídia (digital, impressa, audiovisual);
- Supervisão da adaptação do conceito criativo para diferentes plataformas;
- Coordenação entre equipes criativas de diferentes áreas;
- Garantia de coerência conceitual em todas as expressões do projeto.
