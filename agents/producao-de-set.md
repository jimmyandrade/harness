# Produção de set

## Principais responsabilidades

- Garantir que tudo esteja pronto no set (equipamentos, elenco, figurinos, etc.);
- Supervisionar horários e cronogramas no dia da execução (como em dias de filmagens);
- Resolver problemas que surjam durante a execução (como durante gravações);
- Coordenar a equipe no set para que tudo funcione conforme o planejado.
