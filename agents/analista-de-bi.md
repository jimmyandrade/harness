# Estrategista de dados

## Principais responsabilidades

- Coletar e analisar dados de diferentes fontes (redes sociais, vendas, eventos e, no negócio de música, dados de streaming);
- Desenvolver KPIs e métricas de sucesso para diferentes projetos;
- Criar relatórios e dashboards para acompanhamento de performance;
- Identificar tendências e oportunidades baseadas em dados;
- Realizar análises preditivas para auxiliar no planejamento;
- Trabalhar em conjunto com outras áreas para implementar estratégias baseadas em dados;
- Avaliar o ROI de diferentes iniciativas e campanhas.
