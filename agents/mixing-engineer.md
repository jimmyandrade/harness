# Mixing engineer

## Principais responsabilidades

- Equilibrar adequadamente os elementos sonoros que compõem o conceito sonoro;
- Criar uma imersão sonora;
- Assegurar a qualidade técnica necessária para distribuição nas plataformas digitais, atendendo aos padrões da indústria;
- Valorizar as nuances emocionais presentes nas interpretações;
- Garantir coesão sonora entre todas as faixas.
